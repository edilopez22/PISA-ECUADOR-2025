Impacto del Uso de IA en los Resultados PISA 2025 (Ecuador)

Author

Tu Nombre

Fase 1: Preguntar — Definición del problema

Antes de tocar los datos, definimos la pregunta de investigación aplicando la técnica de los 5 Por Qué, para asegurarnos de que el análisis responde a una necesidad real y no solo a una curiosidad exploratoria.

  1. ¿Por qué nos interesa el uso de IA en el aprendizaje?
    Porque las herramientas de IA se están integrando rápidamente en las aulas y queremos saber si mejoran o perjudican el aprendizaje.

  2. ¿Por qué queremos saber si mejora o perjudica el aprendizaje?
    Porque las políticas educativas (compra de licencias, capacitación docente, restricciones de uso) dependen de evidencia sobre su efecto real.

  3. ¿Por qué necesitamos evidencia y no solo intuición?
    Porque el uso de IA está correlacionado con el nivel socioeconómico (ESCS) y el tipo de colegio, lo que puede generar conclusiones engañosas si no se controla estadísticamente.

  4. ¿Por qué es importante controlar por esas variables?
    Porque sin ese control atribuiríamos a la IA un efecto que en realidad proviene de tener más recursos económicos o estudiar en un colegio privado.

  5. ¿Por qué esto importa para Ecuador específicamente?
    Porque las brechas entre colegios públicos y privados son amplias, y entender si la IA amplía o reduce esa brecha es clave para diseñar política pública focalizada.

Pregunta de investigación: ¿Cuál es el efecto del uso de herramientas de IA sobre el desempeño en matemáticas (PISA) de estudiantes ecuatorianos, una vez controlado el nivel socioeconómico, y ese efecto difiere entre colegios públicos y privados?

Hipótesis de trabajo:

  • H1: El uso de IA tiene una relación no lineal (forma de U invertida) con el desempeño: ayuda hasta cierto punto y luego perjudica (dependencia, distracción).
  • H2: El efecto difiere por sector institucional (público vs. privado).

Nota: el script original mencionaba “urbano vs. rural”, pero la variable realmente disponible en el código es SC013Q01TA (sostenimiento del colegio: público/privado). Mantengo esa comparación porque es la que existe en los datos; si tienes una variable de ubicación (por ejemplo, tipo de comunidad SC001Q01TA), avísame y agrego esa comparación también.

Fase 3: Procesar y limpiar los datos

Construimos un único dataset analítico (pisa_analisis) con todas las variables que se usarán en el resto del análisis, para evitar duplicar limpieza en distintos bloques.

Code 
pisa_analisis <- pisa_completa %>%
  mutate(
    # Variable de sexo: 1 = mujer, 0 = hombre (según codificación ST004D01T)
    female = ifelse(ST004D01T == 1, 1, 0),
    # Sector institucional a partir de la pregunta del director (2 = privado)
    es_privado = ifelse(as.numeric(SC013Q01TA) == 2, "Privado", "Público"),
    # Cuartiles de intensidad de uso de IA (1 = bajo, 4 = muy alto)
    uso_ia_cuartil = ntile(AIUSESCH, 4)
  ) %>%
  select(
    student_id = CNTSTUID,     # ID del estudiante
    school_id  = CNTSCHID,     # ID del colegio
    escs       = ESCS,         # índice socioeconómico
    female,                    # sexo (1 = mujer)
    es_privado,                # sector institucional
    uso_ia     = AIUSESCH,     # índice de uso de IA
    uso_ia_cuartil,            # cuartiles de uso de IA
    w_fstu     = W_FSTUWT,     # peso muestral final del estudiante
    starts_with("PV") & contains("MATH")  # PV1MATH ... PV10MATH
  ) %>%
  # Eliminar observaciones sin información clave para el análisis
  drop_na(escs, uso_ia, female, es_privado)

# Variable de tratamiento dicotómica: 1 = uso de IA por encima de la mediana
pisa_analisis <- pisa_analisis %>%
  mutate(tratamiento_ia = ifelse(uso_ia > median(uso_ia, na.rm = TRUE), 1, 0))

4.8 Modelo no lineal, robusto a los 10 valores plausibles (PVs)

PISA reporta 10 valores plausibles del desempeño (en vez de un solo puntaje) para representar la incertidumbre de la medición. Estimamos el modelo cuadrático en cada uno y promediamos los coeficientes:

Code 
pvs <- paste0("PV", 1:10, "MATH")

modelos_pvs <- lapply(pvs, function(pv) {
  formula <- as.formula(paste(pv, "~ uso_ia + I(uso_ia^2) + escs + female | school_id"))
  feols(formula, data = df_match, weights = ~w_fstu, cluster = ~school_id)
})

# Promediar coeficientes de los 10 modelos (uno por cada PV)
coef_promedio <- rowMeans(sapply(modelos_pvs, coef))

5.3 Curva en U invertida y punto óptimo de uso

Code 
# 1. Extracción segura de coeficientes
b1 <- coef_promedio["uso_ia"]

# Se busca el coeficiente cuadrático probando las dos formas en que fixest nombra la variable
b2 <- if ("I(I(uso_ia^2))" %in% names(coef_promedio)) {
  coef_promedio["I(I(uso_ia^2))"]
} else {
  coef_promedio["I(uso_ia^2)"]
}

# 2. Cálculo del punto óptimo
optimo <- -b1 / (2 * b2)

# 3. Malla de valores de uso de IA para la predicción
grid_ia   <- seq(min(df_match$uso_ia), max(df_match$uso_ia), length.out = 100)
base_y    <- mean(df_match$PV1MATH, na.rm = TRUE)
pred_pisa <- base_y + (b1 * grid_ia) + (b2 * (grid_ia^2))

df_curva <- data.frame(uso_ia = grid_ia, pv_pred = pred_pisa)

# 4. Gráfico con ggplot2
ggplot(df_curva, aes(x = uso_ia, y = pv_pred)) +
  geom_line(color = "#2b5c8f", linewidth = 1.2) +
